How to Read Orbital Parameters

  • Periapsis / Apoapsis: Closest and farthest points in orbit.
  • Semi-major Axis: Average distance between the object and its parent body.
  • Eccentricity: How circular (0) or elliptical (closer to 1) the orbit is.
  • Orbital Period: Time to complete one orbit.
  • Average Orbital Speed: How fast it travels around the parent.
  • Inclination: Tilt of the orbit relative to a reference plane.
  • Longitude of Ascending Node: Angle where orbit crosses reference plane.
